# Evaluation

Reproduce everything on this page with `make eval` (offline, no API key; the embedding model is
downloaded once into `eval/.cache`). The dataset is generated by `eval/build_conflicts.py` with a
fixed seed; the harness is `eval/harness.py`.

How to read it:

- **Recall@1**: the current value is the first result. **Stale@1**: the outdated value is the first
  result. **Stale in top 5**: the outdated value appears anywhere in the results.
- In configs b, c and d, the search settings are ctxbook's defaults (recency weight 0.02; keyword
  mode 0.2). Config b with a strong recency boost appears in the recency sweep at the bottom.
- Configs c and d use an **oracle** client AI that always settles a flagged conflict correctly.

## Limits

- The dataset is synthetic and template-based. The tuned settings are re-checked on LongMemEval
  (knowledge-update questions) before being treated as final.
- Latency was measured on one Intel Mac (CPU only); expect it to vary by machine.
